Equipos del generador

Definí las parejas (o tríos) de equipos y el máximo de días por mes que va a hacer cada uno. El generador balancea automáticamente y rota los fines de semana.

Colores de personas

Tocá el círculo de color de cada persona para cambiarlo. El cambio se aplica en todas las vistas. Útil cuando alguien cambia de equipo.

Sincronización en la nube

Sincronizá los datos entre tu PC y celular usando Firebase (gratis).

Setup (1 vez):
1. Andá a console.firebase.google.com y creá un proyecto
2. En el proyecto: "Build → Realtime Database → Create Database" (modo bloqueado está OK)
3. "Build → Authentication → Sign-in method → habilitá Email/Password"
4. En "Project Settings → General → Your apps → web app", copiá los datos abajo
